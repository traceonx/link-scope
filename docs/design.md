# 界面设计

0.6.0 起参考 MoviePilot（Vuetify 3 / Materio 后台模板）的风格：

- 布局：左侧导航抽屉（宽 260px，桌面可折叠为 76px 图标栏，手机端为浮层）+ 顶部吸顶应用栏（毛玻璃背景；页面标题、全局搜索、扫描中状态、主题切换、版本号）
- 导航分组：清理（仪表盘、扫描、清理结果）/ 管理（下载器、回收站）/ 系统（设置）；选中项为右侧圆角的紫色渐变胶囊，项右侧显示计数或状态（待清理文件夹数、扫描中、新版本）
- 页面：
  - 仪表盘：待清理主卡片、清理概览（四项统计）、空间构成环形图、站点占用（做种 / 孤儿 / 已删种 + 站点条形图）、最近扫描与警告
  - 扫描：扫描目录卡片（下载目录、媒体库目录）、扫描选项、扫描预设；扫描中顶部显示分阶段进度
  - 清理结果：按文件夹 / 按文件、状态标签页、搜索、站点筛选、导出 CSV；右侧详情抽屉；勾选后吸底批量操作卡片
  - 下载器：每个下载器一张卡片（地址、路径映射、种子匹配情况），添加 / 编辑在弹窗中
  - 回收站：统计卡片 + 列表（恢复、永久删除、清空）
  - 设置：标签页 外观与显示 / 运行配置 / 版本与更新
- 配色：浅色背景 #F4F5FA、卡片 #FFFFFF；深色背景 #28243D、卡片 #312D4B；主色 #9155FD。状态色：已整理 蓝 #16B1FF、待清理 橙 #FFB400、部分游离 / 重复 紫、STRM 青、失效 红 #FF4C51、做种 绿 #56CA00。卡片圆角 10px、阴影 `0 2px 10px rgba(58,53,65,.1)`
- 图标：Material Design Icons（`@mdi/js`）
- 字体：Noto Sans SC（系统回退 PingFang SC / 微软雅黑），路径用等宽字体
