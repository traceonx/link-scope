# 界面设计

设计稿（Claude Design）：网页版扫描结果页 + 手机端。

- 扫描设置：检测文件夹、查找目录、包含子文件夹 / 忽略小文件、重复检测方式
- 统计：文件总数、已硬链接、未链接、硬链接节省空间；重复副本 / 软链接 / STRM 小卡片（点击即筛选）
- 结果列表：全部 / 已链接 / 未链接 / 重复副本 / 软链接 / STRM / 失效 筛选，搜索，分页，导出 CSV
- 详情面板：源文件与全部硬链接路径、重复副本、软链接 / STRM 指向；按情况给出原因提示

配色：背景 #F4F5F7，主色 #1F5FD6；已链接 蓝、未链接 橙、重复 紫、STRM 青、失效 红；支持深色模式。
字体：Noto Sans SC（系统回退 PingFang SC / 微软雅黑），路径用等宽字体。
